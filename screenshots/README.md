This folder contains screenshots of the DC Motor Speed Control Using PID Controller project developed in MATLAB/Simulink.
## Screenshot List

1. `01_Speed_Response.png` — Reference speed versus actual motor speed.
2. `02_Transient_Response.png` — Transient response showing rise time, settling time, and overshoot.
3. `03_Load_Disturbance_Response.png` — Motor speed response under load disturbance.
4. `04_Performance_Metrics.png` — Table of calculated performance parameters.
5. `05_DC_Motor_Performance_Outputs.png` — MATLAB Command Window showing calculated results.
6. `06_Simulink_Model.png` — Complete Simulink model of the DC motor PID controller.

These screenshots provide visual documentation of the simulation model, output response, and calculated performance metrics.
