
# MATLAB Code — DC Motor PID Speed Control

This folder contains MATLAB scripts used to analyse the DC Motor Speed Control Using PID Controller project.
## Code Files
1. `01_Performance_Analysis.m` — Extracts the motor speed data, calculates performance metrics, and plots the speed response.
2. `02_Transient_Response.m` — Generates the transient response graph and displays rise time, settling time, and percentage overshoot.
3. `03_Load_Disturbance_Response.m` — Plots the motor speed response under load disturbance.
4. `04_Performance_Metrics.m` — Generates a table containing the calculated performance parameters.
